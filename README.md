# agro-front

Front-end web para el catálogo botánico y agronómico de plantas y familias.

## Scripts

- `npm run dev`: Inicia el servidor de desarrollo Vite.
- `npm run build`: Compila TypeScript y genera el bundle de producción.
- `npm run lint`: Ejecuta ESLint con reglas estrictas y plugins locales.
- `npm run typecheck`: Valida el tipado estricto con `tsc -b`.
- `npm run test`: Ejecuta la suite de pruebas unitarias y de contrato con Vitest.
- `npm run test:coverage`: Ejecuta la suite con informe de cobertura.
- `npm run check`: Ejecuta validaciones de tipos, linting y formato Prettier.
- `npm run check:colors`: Comprueba que no existen colores literales fuera de los tokens de diseño.
- `npm run check:emoji`: Comprueba que ningún archivo de interfaz contenga emojis o símbolos prohibidos.
- `npm run check:ui-text-bypass`: Comprueba que no existan bypasses a la regla de textos de interfaz.
- `npm run icons:generate`: Genera el catálogo estático de glifos SVG vectoriales a todo color.
